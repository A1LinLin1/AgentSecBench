七步判断流程

  1. 真实操作：代码是否真的执行候选操作，而非仅导入、声明或字符串？
  2. Agent 路径：它是否属于 Agent 的工具、能力或可达执行路径？
  3. 输入来源：影响效果的值来自用户、网页、文件、工具输出还是固定常量？
  4. 依赖：能否从来源追踪到危险参数或控制分支？同一文件出现不算依赖。
  5. 边界：是否跨越信任域、权限域、进程、主机或外部服务边界？
  6. 防护：是否真正限制危险路径？日志、异常捕获和类型提示通常不是防护。
  7. 结论：危险能力本身不是漏洞。只有可达路径、弱点和影响均有证据时才确认漏洞。
